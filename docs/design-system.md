# Design system
Tokens live in `frontend/src/index.css` (CSS variables) and are mapped in `tailwind.config.js`.
- Accent: deep teal (light `#0E7470`, dark `#2DBEB4`). Sidebar is always a dark ink-teal.
- Stat gradients: teal→emerald, indigo→sky, amber→orange, rose→fuchsia.
- Type: Instrument Sans. Light bg is warm paper; dark bg is deep neutral with slightly lighter cards (not inverted).
- Logo: three linked nodes (memory graph). Original work; template screenshot used as layout reference only.
